# trotot — Frontend Sprint 1

Next.js App Router, TypeScript, Tailwind/Shadcn, Zustand, TanStack Query và Axios.

Đọc [hướng dẫn frontend](../docs/FRONTEND_SPRINT1_SETUP.md) để tạo `.env.local`, chạy backend và cài dependency bằng `npm ci`. Node khuyến nghị: 24.15.0. Không đưa `.env.local` vào Git.

Web local: `http://localhost:3000`. Các trang Auth gồm đăng ký, đăng nhập, OTP, quên/reset mật khẩu và tài khoản. OTP mock chỉ dùng local/dev. Các trang trọ/homestay dùng dữ liệu mẫu; upload server riêng đang hoãn.

Kiểm tra từ thư mục `frontend/`: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
